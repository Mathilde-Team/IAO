# Raccourcis clavier

Tous les raccourcis d'IAO fonctionnent quand le focus est dans l'application hôte
(barre d'onglets, cartes de comptes, panneaux). Quand le focus est à l'intérieur d'une
page IA (webview), les touches ne remontent pas jusqu'à l'application : cliquez d'abord
hors de la page, ou utilisez les raccourcis propres au site affiché.

## Palette rapide

| Raccourci | Action |
|---|---|
| `Ctrl+K` | Ouvre la palette rapide |
| `Entrée` | Ouvre le service sélectionné dans la palette |
| `Échap` | Ferme la palette (et les fenêtres modales) |

La palette (aussi accessible par le bouton à côté des compteurs « Comptes actifs »)
permet d'ouvrir n'importe quel service avec n'importe quel compte au clavier : tapez le
nom du compte ou du service, puis `Entrée`. La carte du compte utilisé se déplie
automatiquement.

## Onglets

| Raccourci | Action |
|---|---|
| `Ctrl+Tab` | Onglet suivant |
| `Ctrl+Maj+Tab` | Onglet précédent |
| `Alt+1` … `Alt+9` | Ouvrir directement le Nᵉ onglet |

Ces raccourcis parcourent les onglets de comptes. `Ctrl+W` (fermer la fenêtre dans
Electron) est volontairement écarté : fermez un onglet par son bouton `×`.

## Éditeur intégré

| Raccourci | Action |
|---|---|
| `Ctrl+S` | Sauvegarder le fichier en cours d'édition |

Fonctionne dans l'éditeur Monaco et dans l'éditeur de secours.

## Dans une page IA

À l'intérieur d'une page IA, les raccourcis du site lui-même s'appliquent
(rechargement, zoom, outils de développement…). Pour revenir aux raccourcis d'IAO
(listés ci-dessus), cliquez dans l'application hôte — par exemple sur la barre
d'onglets.
